The problem — known firsthand

14,000 pages. One desk. No margin for error.

Public-health procurement committees cross-check tender packs of hundreds of pages by hand. Backlogs delay hospital supplies; thin award documentation is exactly what lets fraud go unchallenged. This is a desk the builder knows firsthand — the users are named, the backlog is real, and the constraint is hard: procurement data must never leave the jurisdiction.

Backlog

Packs of hundreds of pages per tender; committees reviewing by hand delay awards for months.

Fraud surface

Price outliers, missing compliance documents, spec deviations — hidden in volume nobody can read.

The constraint

Sovereignty. Hosted-only drafting is a non-starter — the model must run where the data lives.

The system

A review desk with a structural halt

A LangGraph.js review graph orchestrates the run; a purpose-built MCP server (JSON-RPC 2.0 over HTTP) exposes five review tools and thirteen cycle tools; the official filesystem MCP server provides path-jailed document reads. Every tool call lands in an append-only audit log.

The halt is structural, not behavioral: the edge from the graph to filing does not exist. No prompt, tool misuse or model turn can file an award — filing code only runs after a roster-verified human signature.

The non-negotiable

One button the machine cannot press

Filing an award is irreversible, so the agent cannot do it. The gate refuses the operator until a named approver on the committee roster signs and the roll is quorate. Only then is the bundle sealed with sha-256, filed to the e-GP portal, and a receipt written. The demo's most interesting moment is the refusal.

Why it holds up

Proof, not promises

Deployed, not mocked

quorum-edge.chungu424.workers.dev is a Cloudflare Worker HTTPS front door to the EC2 af-south-1 origin (nginx, systemd) — reproducible from the repo.

Measured model path

The Llama 3.2 drafting path is measured in-repo — cost formula, token counts and the Ollama setup are documented, not claimed.

Safety as tests

49 green tests enforce the rules: no citation, no finding; the halt-at-the-gate guarantee lives in the graph topology.

Tamper-evident record

Append-only audit JSONL captures every tool call — oversight bodies see who decided what, forever.

Eval harness

Held-out tender packs and a pre-registered baseline protocol (SUBMISSION/09-fit.md) — findings are checked, not vibes.

Sovereign by design

Open-weights, in-region drafting keeps procurement data in the jurisdiction — the reason Llama is the primary path.
