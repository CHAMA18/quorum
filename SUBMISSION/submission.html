The problem — Africa-wide, grounded in Zambia

17% of GDP across Africa. 203 procuring entities in Zambia.

Across Africa, public procurement averages about 17% of GDP. In Zambia, ZPPA reported 203 procuring entities and 71,102 suppliers registered on e-GP at the end of 2023. Procurement officers still have to read tender packs, check compliance and document why a recommendation is justified. Quorum helps make that review easier to follow, while leaving the award decision with the authorised committee.

Zambia’s reported figures, in context

FIC’s 2017 estimate of US$450 million covered several suspected offences; approximately US$50 million related to corruption. Separately, FIC analysed 624 suspected procurement-corruption reports. Its 2022 report describes an advance exceeding ZMW 85 million (approximately US$4.25 million) on a February 2021 contract, using the World Bank’s 2021 annual-average rate of ZMW 20.0184866 per US$1 for scale. Another case involved US$32 million paid on a US$215 million contract where FIC reported no works performed. These are distinct historical estimates and case values, not a combined annual loss total. The system

A review desk with a structural halt

A LangGraph.js review graph orchestrates the run; a purpose-built MCP server (JSON-RPC 2.0 over HTTP) exposes five review tools and thirteen cycle tools; the official filesystem MCP server provides path-jailed document reads. Every tool call lands in an append-only audit log.

The halt is structural, not behavioral: the edge from the graph to filing does not exist. No prompt, tool misuse or model turn can file an award — filing code only runs after a roster-verified human signature.

The non-negotiable

One button the machine cannot press

Filing an award is irreversible, so the agent cannot do it. The gate refuses the operator until a named approver on the committee roster signs and the roll is quorate. Only then is the bundle sealed with sha-256, and a local simulation receipt written. No national e-GP transaction is made. The demo's most interesting moment is the refusal.

Why it holds up

Proof, not promises

Deployed, not mocked

d1n7mv5t5hn4xe.cloudfront.net is the live HTTPS front door; the workspace runs on the EC2 af-south-1 origin (nginx, systemd) — reproducible from the repo.

Measured model path

Both paths are measured in-repo: a live Muse Spark run on the KEMSA pack (22.8 s, 2 model drafts, 4 redactions) and the in-region Llama fallback (token counts, cost formula, Ollama setup). The report prints the model string the endpoint actually returned.

Safety as tests

509 tests, 0 fail (4 November 2026) enforce the rules: no citation, no finding; the halt-at-the-gate guarantee lives in the graph topology.

Tamper-evident record

Append-only audit JSONL captures every tool call — reviewers can verify the recorded sequence and detect changes within the stated deployment controls.

Eval harness

Synthetic test packs and a prepared counterbalanced officer study (SUBMISSION/09-fit.md) — independent officer results are pending.

Sovereign by design

Hosted calls are redacted (supplier names and amounts replaced), the in-region Llama fallback keeps the full evidence on the desk, and the residency policy refuses any endpoint the operator has not approved.
