# Solution

> **Briefly describe your solution, how it works, and who will use or benefit from it.**
> *Maximum 200 words.*

---

Quorum helps procurement officers prepare source-linked committee reviews. It starts with Zambia’s public-health procurement context and a wider African need for clearer, accountable purchasing.

Muse Spark on Meta Model API plans document review, drafts redlines and compares admitted bids against issued criteria. The workspace shows the returned model, source quotations and measured response time. Exact quotation checks reject invented evidence; an absence of evidence stays visible. The committee retains official scores, ranking and award authority.

An MCP server and a locally installed filesystem MCP server connect the agent to the tender documents. A LangGraph review stops at a pending human gate. A separate approval path checks identity, office authority, quorum and two-factor verification before sealing a local simulation receipt. HMAC attestation, replay protection, an Ed25519 signature and a hash-chained audit trail make that boundary inspectable.

Evaluation officers get a clearer first-pass file; committee members can inspect the evidence; auditors can trace the decision. The submission combines recorded product workflows with a separate fictional Zambia integration test, and documents a public Kenyan award-register test. It claims no live national e-GP connection, measured officer time saving or recovered funds. A consented, counterbalanced desk study is prepared to test usability, time and material-issue recall.
